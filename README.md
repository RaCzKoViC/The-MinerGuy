## ⛏️ About

**The MinerGuy** is a 2D sandbox where every world is procedurally generated from a seed: dig from the surface through the underground, crystal caverns and magma-filled deep mines down to the World Core, build a home and a settlement, craft your way from a basic pickaxe to advanced industry, and take on seven major guardians. After the finale the world awakens and keeps going — with spreading Blight and Bloom biomes, flight, new guardians, expedition portals, deep oceans, oil, power grids and logic circuits.

Everything you see and hear — pixel art, fonts, sound effects and music — is generated by the game's own code. The repository ships no third-party game assets.

The current version is **1.32.1**, a fully English **1.32.0 — Right where you left off**: a loaded game puts your character **exactly where it stood** when you saved (even in a boat), and the main menu has a **Continue** button for your last save. It follows **1.31.0 — Fair forge** (worn tools and weapons are **repaired instead of lost**, tools last about twice as long, classic metals no longer skip the guardians), **1.30.0 — Shared factory** (in co-op the **host runs the whole factory**, fire and heat; guardians drop loot for **every player taking part**) and **1.29.1 — Safe ground** (the game **updates itself from the main menu**). See the [release history](CHANGELOG.md).

## ✨ Features

- 🌍 **Procedural worlds** — deterministic seeds with surface, caverns, deep oceans, reefs, wrecks and the World Core, up to *Huge* 6000×1800 tiles.
- ⛏️ **Mine, build, craft** — hundreds of items and recipes, a searchable recipe book, recipe tracking on the HUD, furniture, slopes and item modifiers.
- 🐉 **Guardians and events** — seven major guardians, biome guardians, invasions, storms, eclipses, blood-red dusks and dynamic world events.
- 🏘️ **Settlements** — settlers with housing, shops, quests, reputation, settlement ranks and timed expeditions.
- ⚙️ **Automation and industry** — wiring, logic gates, sensors, minecarts, pumps and pipelines, oil refineries, generators, batteries and power grids.
- 🌊 **Ocean depths** — diving gear, boats, sea creatures and the Leviathan.
- 🎣 **Survival life** — farming, fishing, hunting, cooking, weather, day and night.
- 🧑‍🤝‍🧑 **Co-op for up to 8 players** — LAN discovery, direct IP, Internet invite codes, automatic reconnect and a headless dedicated server.
- 🎨 **Your character** — character editor, skills up to level 1000, achievements and avatar frames.
- 💡 **Atmosphere** — directional sunlight and shadows, point-light shadows, bloom, god rays, underwater caustics, heat haze and cave fog.
- 🎮 **Comfort** — XInput controller support in gameplay and menus, rebindable keys, UI scale 100–200%, Polish and English interface.
- 💾 **Safe saves** — atomic writes with automatic `.bak` recovery and tested compatibility with older worlds.

## 📥 Download and install

Get the latest build from **[GitHub Releases](https://github.com/RaCzKoViC/The-MinerGuy/releases/latest)**. Two options are published for every release:

| File | What it is |
|---|---|
| `TheMinerGuySetup-<version>.exe` | **Recommended.** Per-user installer — no administrator rights needed. Installs to `%LOCALAPPDATA%\Programs`, adds Start menu and desktop shortcuts and a normal uninstaller. |
| `TheMinerGuy-<version>-win-x64.zip` | Portable build — unzip anywhere and run `MinerGuy.exe`. |

Both builds are self-contained: **no .NET installation is required.** Your worlds and characters live in `%LOCALAPPDATA%\MinerGuy` and are kept when you upgrade or uninstall the game.

> [!NOTE]
> **Windows SmartScreen:** the builds are not code-signed yet, so Windows may show *"Windows protected your PC"* the first time. Click **More info → Run anyway**. Only download the game from this repository's [Releases page](https://github.com/RaCzKoViC/The-MinerGuy/releases) or the [official website](https://raczkovic.github.io/The-MinerGuy/).

The game starts in English (in Polish when Windows is set to Polish); change the language in **Settings** from the main menu.

From version 1.29.1 on, the game **updates itself**: when a new version is out, the main menu offers it with the release notes, backs up your saves and restarts updated.

## 🎮 Controls

| Input | Action |
|---|---|
| `A` / `D` | Move left or right |
| `Space` / `W` | Jump, swim upward or climb |
| `S` | Drop through a platform or climb down |
| Left mouse button | Mine, attack, fire or place the selected item |
| Right mouse button | Interact with doors, chests, beds, settlers and devices |
| `1`–`0` / mouse wheel | Select a hotbar slot |
| `E` / `C` | Inventory and crafting / crafting panel |
| `B` | Recipe book |
| `J` / `K` | Miner Journal / skills |
| `M` / `N` | World map / minimap |
| `H` / `F` | Quick heal / interact with the nearest object |
| `Q` | Drop the selected item |
| `Esc` / `F12` | Pause or close panel / screenshot |

Keyboard bindings can be changed in the settings. XInput controllers are supported throughout gameplay and menus.

## 🧑‍🤝‍🧑 Co-op multiplayer

Up to **eight players** can share one host-authoritative world.

1. **Host:** load a world, press `Esc` and choose **Open to LAN** (default TCP port `7777`) or **Open to Internet** — Internet invite codes then appear in the `Esc` menu.
2. **Friends:** choose **Multiplayer** in the main menu, then pick the world from the LAN browser (UDP discovery on port `7778`), type the host's IP address, or paste an invite code with `Ctrl+V`.
3. **Dedicated server:** run a headless server without a game window:

   ```powershell
   MinerGuy.exe --server "World name" [--port 7777] [--bind <address>] [--internet]
   ```

Internet play needs an open port, UPnP or a VPN when direct inbound connections are not possible. Dropped players reconnect automatically; guardian fights, chat, portraits and minimap markers are shared. PvP is not part of the game design.

## 🐞 Bug reports and crash logs

Found a bug? **[Open a bug report](https://github.com/RaCzKoViC/The-MinerGuy/issues/new?template=bug_report.yml)** — the form asks for everything needed to reproduce it. Ideas are welcome as **[feature requests](https://github.com/RaCzKoViC/The-MinerGuy/issues/new?template=feature_request.yml)**.

If the game crashes, it writes the details to a file in:

```text
%LOCALAPPDATA%\MinerGuy\Logs
```

Paste that path into the File Explorer address bar, then attach the newest `crash-<date>.log` file to your report (the logs stay on your computer; nothing is sent automatically). Please also mention your game version, Windows version and GPU. Security problems should be reported privately — see [SECURITY.md](SECURITY.md).
