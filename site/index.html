Better with friends

  1. Host Load a world, press Esc and choose “Open to LAN” or “Open to Internet” to get an invite code.
  2. Join Pick “Multiplayer” in the main menu: choose a LAN game, type an IP address or paste the invite code.
  3. Play Up to 8 players share guardian fights, chat and minimap markers. Dropped players reconnect automatically.

Want a world that is always on? Run a headless dedicated server: MinerGuy.exe --server "World name"

Get started

System requirements

  • Windows 10 or 11, 64-bit
  • GPU with OpenGL 3.x support
  • About 80 MB of disk space, plus your worlds
  • No .NET install needed — everything is bundled
  • Keyboard + mouse or an XInput controller

Install in a minute

  1. Download TheMinerGuySetup-<version>.exe with the button above.
  2. Run it — no administrator rights needed.
  3. If SmartScreen says “Windows protected your PC”, click More info → Run anyway (the build is not code-signed yet).
  4. Saves live in %LOCALAPPDATA%\MinerGuy and survive updates.
