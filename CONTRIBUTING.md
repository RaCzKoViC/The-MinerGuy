# Feedback and bug reports

Thank you for playing The MinerGuy! The game's source code is not public, so pull requests
cannot be accepted — but your reports make the game better. You can write in English or Polish.

- **Bugs and crashes:** [open a bug report](https://github.com/RaCzKoViC/The-MinerGuy/issues/new?template=bug_report.yml).
  Please include the game version (main menu, bottom corner), your Windows version and GPU, the
  steps that lead to the problem and, after a crash, the newest `crash-<date>.log` from
  `%LOCALAPPDATA%\MinerGuy\Logs`.
- **Ideas:** [suggest a feature](https://github.com/RaCzKoViC/The-MinerGuy/issues/new?template=feature_request.yml).
- **Security problems:** report them privately — see [SECURITY.md](SECURITY.md).

Search the [existing issues](https://github.com/RaCzKoViC/The-MinerGuy/issues) first and keep one
problem per report. Reports are public: do not include personal data you do not want to share.

By sending feedback you allow the author to use it to fix and develop the game (see section 4 of
the [LICENSE](LICENSE)).
